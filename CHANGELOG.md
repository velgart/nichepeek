# Changelog

## 0.3.5 (first public release)

First public release. Version numbers before 0.3.5 were internal development versions. The results of the
accompanying paper were computed with the same code: no computation has changed since then, so per-section
results of `run` are unchanged. User-facing text (the report, command-line output, the reading and the README)
uses the paper's term "neighborhood share"; key and column names keep `program`, so saved runs stay readable.
